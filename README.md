# diet-website

سایت عمومی **رژیم من** (خانه، تعرفه‌ها، مقالات، تماس، …) — استخراج‌شده از مخزن اصلی [My-Diet](https://github.com/mahdi899/My-Diet) برای کار روی UI بدون کل مونوریپو.

## اجرای محلی

```bash
npm install
npm run dev
```

مرورگر: `http://127.0.0.1:3000`

## مقالات و API

- پیش‌فرض: محتوا از `public/magazine.json` (بدون بک‌اند).
- اگر Laravel روشن باشد، سرور مسیر `/v1` را به `http://127.0.0.1:8000` پروکسی می‌کند (`SABZINE_API_TARGET`).

## ساخت

```bash
npm run build
npm run preview
```

## همگام‌سازی با مونوریپو

منبع حقیقت صفحات سایت:

`My-Diet/frontend/src/features/site/`

پس از تغییر در این مخزن، در صورت نیاز همان فایل‌ها را به مسیر بالا در My-Diet کپی کنید (یا برعکس).

## Google AI Studio

این پروژه شامل سایت و ویزارد انبوردینگ منتقل‌شده از `My-Diet/frontend` است. پنل‌های ادمین و دکتر در این مخزن نیستند.
## انبوردینگ

مسیرهای `/onboarding`، `/onboarding/goals`، `/onboarding/quiz` و `/onboarding/payment` ویزارد اصلی را اجرا می‌کنند. `/onboarding.html` به مسیر اصلی هدایت می‌شود.

فایل‌های رابط در `src/features/onboarding` و داده‌ها و رسانه‌ها در `public/onboarding` هستند. پیشرفت پرسش‌نامه مانند پروژهٔ اصلی در مرورگر نگه داشته می‌شود.

برای ثبت پاسخ‌ها، پیامک و پرداخت، بک‌اند Laravel پروژهٔ My-Diet را اجرا کنید. سرور توسعه و تولید درخواست‌های `/v1` را به `http://127.0.0.1:8000` می‌فرستد؛ آدرس با `SABZINE_API_TARGET` قابل تنظیم است. فرمان `npm run dev` به‌صورت پیش‌فرض پورت ۳۰۰۰ را اجرا می‌کند (`PORT` قابل تنظیم است).
